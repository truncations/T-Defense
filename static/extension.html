SET UP ONCE. ACTIVATE ON A TAB.

Start protecting a page

  1. Load the extension

    Extract the download. Open chrome://extensions or edge://extensions, enable Developer mode, and choose Load unpacked. Select the extracted folder containing manifest.json.

  2. Pair with this backend session

    Copy the code below. Open the T-Defense toolbar popup, paste it, and select Pair backend. The code expires when this server restarts.

  3. Open a website and start monitoring

    On your chosen tab, open the extension and select Start monitoring this page. Checks repeat about every 8 seconds and after page changes while visible. Activate again after moving to another site.

Clear about what it checks.

Checks: misleading link addresses, pressure plus sensitive requests, unencrypted sensitive forms, forms sending to another origin, and potentially risky downloads.

Doesn’t collect: passwords, typed values, raw messages, full page HTML, cookies, or browsing history. Only standardized structural flags and site origins go to this computer’s backend.

Limits: these are rule-based clues, not proof of phishing. Legitimate pages may trigger a warning. Embedded frames, closed components and attachment contents are not scanned. Programmatic submissions, earlier page handlers and middle/context-menu clicks may evade interception. Hostile pages can interfere with page overlays; the extension toolbar also shows warning counts.
